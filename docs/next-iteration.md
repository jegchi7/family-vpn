# Следующая итерация после v0.28.0

## RU ingress и isolation · v0.28

По запросу владельца следующий шаг сосредоточен на native acceptance созданных RU/Foreign IPv4 network tools: независимый Ubuntu20.04 inventory и helper pins, nft JSON positive/negative readback, защита при partial failure и отсутствие direct/DNS/private/metadata/IPv6 обходов. Baseline host forwarding0 остаётся blocked до сохранения all/default/interface sysctls и NIC LRO state; не включать его скрытым bootstrap. Далее dedicated unprivileged core foreground/systemd runtime с guard/boot order и vault-bound current client issuance, затем Android TCP/UDP/DNS/Foreign-loss/management/resource tests. Empty clients, parser check, prepared artifact и TTL proof не становятся profile ready. AWG/TUN и backup/TLS acceptance остаются открыты. Network helpers в локальной разработке не запускались; VPS/routes/firewall/SSH не изменялись. Отчёт iteration-28.md, runbook network-stand-runbook.md, canonical snapshot1.23 (41/19/3/0), схемы6/4/1.
