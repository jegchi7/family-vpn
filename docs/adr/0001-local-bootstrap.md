# ADR-0001 — локальный read-only bootstrap

Статус: принято для итерации 01. Не заменяет нормативные ADR-001…007 сетевой платформы.

Пока нет текущего обследования VPS, готовим DEV-01 и тестируемые seams для следующих задач на fixtures. Два процесса/listener, numeric loopback, явный --demo, read-only HTTP. Три привилегированных будущих бинарника завершаются с exit 2. Это предотвращает ложное впечатление готовой инфраструктуры.

Go stdlib без внешних Go dependencies. Svelte + Vite с lockfile; OpenAPI JSON 3.1 генерирует TS DTO. Нет отдельного собственного API-клиента, подменяющего контракт. Fixed demo identity не используется как production auth. Никаких публичных deploy scripts и CI auto-deploy.

Данные fixtures живут в памяти, стареют; UI не обновляет timestamp для создания видимости измерения. Файлы содержат только текст «НЕ VPN-КОНФИГ». Нет приватных ключей и адресов настоящих серверов.

Риски: нет production security, SQLite и реальных адаптеров. Последствия: нужно заменить fixture store через интерфейс repository, добавить AUTH и отрицательные тесты до реального доступа; закрытые services остаются fail-fast до конкретной реализации.
